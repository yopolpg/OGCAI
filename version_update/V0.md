# 📦 OGCAI - Version 0.0 Baseline (Full Local System Backup)

> **สถานะเวอร์ชัน:** `Version 0.0 - Baseline (100% Local Offline AI Engine)`  
> **ความสมบูรณ์:** `Phase 1 - Phase 5 เสร็จสมบูรณ์ 100%`  
> **รูปแบบการทำงาน:** `Local-Only (ออฟไลน์ 100% ทำงานผ่าน Ollama และ Local Storage)`

## 1. บทสรุปความสามารถของ Version 0 (V0 Feature Summary)

Version 0 คือระบบผู้ช่วย AI ส่วนบุคคลที่ทำงานในเครื่องแบบออฟไลน์ 100% ไม่ต้องต่ออินเทอร์เน็ต และเก็บข้อมูลทั้งหมดไว้ในเครื่องโดยสมบูรณ์:

1. **🔄 2-Tier Auto-Model Switcher Engine:**
   - **Tier 1 (Regex 0ms):** สลับโมเดลทันทีด้วย Pattern Matrix ตรวจจับโจทย์คำนวณ โค้ดดิ้ง หรือคำปรึกษาชีวิต
   - **Tier 2 (AI Classifier ~50-100ms):** ใช้ `qwen2.5:3b` คัดแยก Intent ของคำถามที่ไม่ตรง Regex
   - **Manual Override:** เลือกโมเดลที่ต้องการได้เองผ่าน UI Badge
2. **🧠 High-Capacity Multi-Tier Memory (150GB+ Storage):**
   - **Short-Term Context:** จัดการประวัติแชทแบบ Real-time
   - **Long-Term Profile:** SQLite (WAL Mode) พร้อม Background Memory Worker ดึงข้อมูลสำคัญเก็บลงโปรไฟล์ผู้ใช้
   - **Semantic Knowledge Vault:** ChromaDB Vector Storage สำหรับ Indexing เอกสารส่วนตัว (`.pdf`, `.md`, `.txt`, `.csv`) ใน `storage/vault/`
   - **Favorite Memory:** ระบบกดติดดาว ⭐ คำตอบสำคัญเพื่อดึงมาใช้งานซ้ำ
3. **🛠️ Specialized Precision Modules (4 หมวดหลัก):**
   - **💰 Finance:** แปลง NLP รายรับ-รายจ่าย, คำนวณดอกเบี้ยทบต้น, กฎ 50/30/20, สร้างกราฟสถิติ Dark Theme
   - **🩺 Health & Habits:** บันทึก Habit Streaks, ออกแบบ Routine ตารางเวลาชีวิตประจำวัน
   - **📚 Study:** สรุปบทเรียน, วาง Milestone Roadmap, สกัด Flashcards, สร้าง Quiz แบบทดสอบ
   - **⚙️ Python Sandbox:** รันโค้ดคำนวณและพล็อตกราฟ Matplotlib ปลอดภัยผ่าน Subprocess Isolation
4. **🎨 Minimalist Dark Glassmorphism Frontend:**
   - หน้าต่างสนทนาแบบ Zero-Clutter คลีนตา ใช้งานง่าย
   - Categorized Drawer แถบเครื่องมือ 5 หมวดหมู่พับเก็บได้
   - Real-time Server-Sent Events (SSE) Token Streaming
5. **🔒 Security & System Scripts:**
   - Directory Traversal & Path Sandboxing Guard
   - ระบบ Auto-Backup ฐานข้อมูลอัตโนมัติลง `storage/db/backups/`
   - สคริปต์เปิด-ปิดระบบในคลิกเดียว ([run_ogcai.bat](file:///d:/OGCAI/run_ogcai.bat), [stop_ogcai.bat](file:///d:/OGCAI/stop_ogcai.bat))

## 2. การจัดสรรโมเดล AI ใน Version 0 (V0 Model Allocation)

| หน้าที่การทำงาน | โมเดลที่กำหนด | จุดเด่น |
| :--- | :--- | :--- |
| **Default Model (สนทนาทั่วไป/ภาษาไทย)** | `qwen2.5-coder:7b` | ภาษาไทยสละสลวย รวดเร็ว โค้ดดิ้งทั่วไปแม่นยำ |
| **Advisor Model (ให้คำปรึกษา/สุขภาพ/ชีวิต)** | `llama3.1:8b` | ให้มุมมองเชิงลึก ปรัชญา จิตวิทยา เป็นธรรมชาติ |
| **Heavy Logic (ตรรกะซับซ้อน/คณิตศาสตร์)** | `deepseek-coder-v2:16b` | ตรรกะสูง คำนวณหลายชั้น พิสูจน์สมการ |
| **Fast Classifier / Background Worker** | `qwen2.5:3b` | ความเร็วสูง ใช้สกัดความจำและคัดแยก Intent |
| **Fallback Model (สำรองฉุกเฉิน)** | `phi3.5:latest` | สเปกเบา สำหรับเครื่องโหลดสูง |

## 4. วิธีการ Restore / Rollback กลับมาที่ Version 0 (Baseline Guide)

2. ใช้ `RouterService` ในรูปแบบ 2-Tier เดิม (ไม่เรียก external network)
3. รันผ่าน [run_ogcai.bat](file:///d:/OGCAI/run_ogcai.bat) ระบบจะทำงานแบบ Local 100% ทันที
