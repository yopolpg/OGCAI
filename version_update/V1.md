## 1. วิสัยทัศน์และการอัปเกรดใน Version 1 (V1 Upgrade Vision)

Version 1 เป็นการยกระดับ OGCAI ให้เป็นระบบ **Hybrid AI Engine** ที่ดึงพลังของ **Cloud AI Free Tier ประสิทธิภาพสูง (Google Gemini 2.5 Flash / Groq)** มาประมวลผลงานยากๆ ที่ต้องใช้การคิดวิเคราะห์หลายชั้น โดยยังคงรักษาจุดแข็งเรื่อง **ความเป็นส่วนตัว 100% และการทำงานออฟไลน์ของ Local AI (Ollama)** ไว้อย่างสมบูรณ์แบบ

```mermaid

    User([ผู้ใช้ป้อนคำสั่ง / อัปโหลดไฟล์]) --> NetCheck{1. ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต\nNetwork Connectivity Probe}
    
    NetCheck -->|Offline ไม่มีเน็ต| LocalEngine[🖥️ Ollama Local Engine\n100% ในเครื่อง / ออฟไลน์]
```

## 2. ฟีเจอร์หลักที่จะเพิ่มใน Version 1 (Core Features)

### 🔑 2.1 Multi-Account API Key Pooling & Rotation (`KeyPoolManager`)
- รองรับการใส่ API Key หลายบัญชีผ่าน `.env` เช่น `GEMINI_API_KEYS=key1,key2,key3`
- **Round-Robin Cycling:** สลับใช้แต่ละบัญชีอย่างเท่าเทียม เพื่อกระจาย Rate Limits (RPM / TPM)
- **Auto-Failover on 429:** เมื่อบัญชีใดติดโควตาชั่วคราว ระบบจะพัก Key นั้นไว้ และสลับไปใช้บัญชีถัดไปทันทีโดยไม่หยุดชะงัก

### ⚡ 2.2 Real-time Network Probe & Seamless Offline Fallback
- ตรวจสอบสถานะการเชื่อมต่ออินเทอร์เน็ตแบบ Non-blocking ใน Background
- เมื่อเน็ตหลุด ระบบจะ Fallback มาใช้ Local Model (`qwen2.5-coder:7b` หรือ `llama3.1:8b`) ทันที 100%

### 🔒 2.3 Privacy Shield & Vault Boundary Guard
- เพิ่มระบบป้องกันความลับขั้นสูง: หากคำถามมี Context จาก `storage/vault/` หรือผู้ใช้เปิดโหมด **Privacy Shield**
- ระบบจะบังคับใช้ Local AI ในเครื่องเท่านั้น ป้องกันข้อมูลรั่วไหลสู่ระบบภายนอกอย่างเด็ดขาด

### 🛡️ 2.4 Repository Security & GitHub Readiness
- สร้าง `.gitignore` และ `.env.example` ป้องกันการเผลออัปโหลด API Keys, ข้อมูลส่วนตัวใน `storage/`, ฐานข้อมูล SQLite และขยะระบบขึ้น GitHub

### 🎛️ 2.5 Hybrid UI & Active Provider Badges
- แสดง Badge ที่มาของคำตอบชัดเจน เช่น:
  - 🟢 `Local: Qwen 2.5 Coder 7B (Offline / Private)`
  - 🔵 `Cloud: Gemini 2.5 Flash (Acc #2 - Online Free)`
- เพิ่มปุ่ม Toggle สลับโหมด: **Hybrid Auto (แนะนำ)**, **Force Local (Privacy)**, **Force Cloud**

## 4. เกณฑ์การตรวจรับ Version 1 (Acceptance Criteria)

1. ✅ **Multi-Account Key Rotation:** สามารถใส่ Gemini Key 3-5 บัญชี แล้วระบบสลับใช้งานได้ถูกต้องเมื่อติด Rate Limit 429
2. ✅ **Privacy Enforcement:** คำถามที่เรียกดูไฟล์ใน Vault จะไม่ถูกส่งไป Cloud AI เด็ดขาด
3. ✅ **Offline Resiliency:** เมื่อตัดการเชื่อมต่อเน็ต ระบบสลับมาตอบด้วย Local Ollama ได้อัตโนมัติ 100%
4. ✅ **Git Safety:** รัน `git status` แล้วไม่พบไฟล์ `.env`, `storage/`, `*.sqlite` หรือไฟล์ API Keys หลุดเข้ามา
